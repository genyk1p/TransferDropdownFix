# Transfer Dropdown Fix

Vessel names in the closed drop-downs of the [Konstruction](https://github.com/UmbraSpaceIndustries/Konstruction) "Transfer resources" window.

Not affiliated with or endorsed by Umbra Space Industries. Konstruction is named here only to say what this mod works with.

Forum thread: https://forum.kerbalspaceprogram.com/topic/231953-112x-transfer-dropdown-fix-012-vessel-names-in-the-konstruction-resource-transfer-window/

## The problem

The two drop-downs of Konstruction's resource transfer window show no vessel name when closed, not even the default "Select a target...", while the open list has the names. So you cannot see which two vessels are selected.

Cause: the caption of each drop-down is 17 px high, while a line of its Arial 16 font needs about 18–19 px. With Unity's default vertical overflow (Truncate) a line that does not fit is not drawn at all.

## What it does

A Harmony postfix on `KonstructionUI.ResourceTransferWindow.ShowWindow` sets the vertical overflow of both captions to Overflow, and the names show up. Konstruction's own files are not modified.

## Requirements

- KSP 1.12.x
- Konstruction (tested with v112.0.1)
- Harmony 2.2.1 or newer (`000_Harmony`)

## Installation

- **CKAN:** search for "Transfer Dropdown Fix" (once it is indexed).
- **By hand:** download the zip from [Releases](https://github.com/genyk1p/TransferDropdownFix/releases) and copy `GameData/TransferDropdownFix` into the game's `GameData` folder. Install Harmony 2 as well if you do not have it yet.

Safe to add to or remove from an existing save: the mod only changes how the window is drawn and saves nothing.

## Building

```
dotnet build src -c Release
```

The build references the game's assemblies and Konstruction's `KonstructionUI.dll`; the KSP install path defaults to the Steam location, override it with the `KSPDIR` environment variable or `-p:KSPDIR=...`. The DLL lands in `GameData/TransferDropdownFix/Plugins`.

## По-русски

В окне передачи ресурсов Konstruction в закрытых выпадающих списках не видно названий кораблей, даже «Select a target...». В раскрытом списке названия есть. Причина: поле подписи ниже строки шрифта, и Unity такую строку не рисует. Мод разрешает подписи выходить за край по высоте, и названия видны. Файлы Konstruction не меняются. Мод можно ставить и убирать в идущую игру: он ничего не сохраняет.
